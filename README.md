# 蘇清的返鲜冰箱 | SuQing's Freshness Fridge

**0.2.0-rc.3** 是 Project Zomboid **B42.22.2 单人密封批次候选**。模组元数据覆盖 B42.21 和 B42.22。本版新增批次记录，沿用冰箱的 Mod ID、建筑和搬运物品 ID、四向贴图及容量设置。

与 Loot Tracker 1.8.5 共用库存选择接口时，保留搜刮记录及密封限制。

工坊更新沿用既有条目。当前公开版本、可见性和上传结果见发布记录。`release/` 下的冻结清单保留准备时状态。 [工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3834692923) · [发布状态](publishing/workshop-item.json)

## 建造

在原生建造菜单选择 **蘇清的返鲜冰箱**。无额外技能门槛。

| 建造输入 | 数量及处理 |
| --- | --- |
| 小金属板 | 4 件，消耗 |
| 电线 | 2 件，消耗 |
| 闹钟、电子表、怀表、经典指针腕表 | 每种 1 件，消耗四件不同实物 |
| 螺丝刀、焊接面罩 | 保留 |
| 焊枪 | 消耗 1 次原生用量，保留工具 |

电子表接受原版 6 种左右手或颜色版本，经典腕表接受 8 种版本。付款、取消和完成沿用原生 BuildLogic。

## 密封返鲜

1. 接通市电、发电机或受支持的 Live Wire 电网，把要返鲜的食物直接放入冰箱。
2. 右键冰箱，选择 **密封冰箱并开始返鲜**。密封时记录本批食物。密封期间无法通过普通库存界面打开冰箱、放入或取出食物。右键菜单可查看剩余时间。
3. 已加载的冰箱累计达到设定的通电游戏时长后，原有食物的年龄归零，原生属性恢复，冰箱自动解除密封。

批次接受直接存放的标准可腐坏 `Food`。装有食物的包、其他物品、受污染食品、烧焦食品、受精蛋和缺少有效保鲜阈值的食品会使封箱失败。开启 `AllowRotten` 后，可以处理仍存在的腐坏食品。

断电、离区、离线、暂停和供电无法确认时不累计返鲜。复电或回区后重新建立观察起点，之前已经确认的进度保留。超过 15 游戏分钟的单次时钟跳变不补算。等待期间按冰箱检查供电和批次进度，食物只在开始、完成和异常恢复时处理。

密封期间暂时使用原生的非腐坏阈值和不可烹饪状态，保护食物免遭原生腐坏流程替换或移除。开封时恢复原值并继续正常老化。批次保留原有物品及其份量、营养、配料和毒素。清单异动时，能够安全恢复的批次会撤销返鲜并解除密封。缺失物品不会重建。

## 沙盒选项

| 选项 | 默认值与范围 | 作用 |
| --- | --- | --- |
| `Enabled` | 开启 | 允许开始新批次。已密封的批次仍可通电完成。 |
| `Capacity` | 200，整数 50–1000 | 新建和已加载冰箱的基础容量。缩小容量时保留现有物品，后续存放受正常容量限制。 |
| `BatchHours` | 12，0.25–24 游戏小时 | 每批要求的已观察通电时长，0.25 小时等于 15 游戏分钟。开始时记录该批时长。 |
| `AllowRotten` | 开启 | 允许把仍存在的腐坏食品加入新批次。 |

容量桥接只覆盖本模组冰箱的普通单人 Lua 存取，保留原生收纳规则和整理有方、杂乱无章的容量影响。直接查询 Java 底层容量的外部模组仍可能遇到普通家具的 100 上限。容量高于 100 时，首次同步及强制同步边界可能出现原生提示。

## 兼容、维护与回退

- 标准等距视角可独立使用。识别到 Viewpoint 时注册附带的独立 3D 模型。
- Live Wire 1.7.2 为可选适配。设备分路断电会暂停计时。加载区块时先等待 Live Wire 完成自然老化和冻融补算，再建立返鲜的供电观察。直接绕过 Lua 存取入口的第三方自动化需要另行验证。
- 蘇清的冷藏性能补丁 `SuQingRefrigerationNative_4221` 是可选的普通冷藏后端。B42.22.2 环境中的 `0.1.0-rc.2` 依赖蘇清的冷藏升级 `1.0.0-rc.2-perf.8` 和 ZombieBuddy。密封批次由本模组的 Lua 实现。更换冷藏后端后请完整退出并重启游戏。
- **回退或停用前先让所有密封批次完成。** 临时保护会随原生存档保存，开封时恢复原值。若界面提示批次需要恢复，保留存档并查看日志。
- 冰箱开封、清空后可通过原生家具流程搬运或拆除。重新放置时应用当前沙盒容量。拆除沿用原生返料规则。移除整个模组前，先完成批次、清空并拆除自定义冰箱，再正常保存退出。

源码保留运行时、原生方法、建造与容量桥接验证工具。发布包包含运行资源和说明。若已完成个人部署，复查应使用对应的部署记录。`tools/release.py` 的发行前检查面向未安装候选。

- `tools/runtime_run_tests.py` 用于运行时与原生 Food 方法验证。
- `tools/building_validate.ps1` 和 `tools/capacity_validate.py` 用于建造、搬运、原生 Lua 转移和容量边界验证。
- `tools/assets_validate.py` 用于纹理包、模型及四向绑定读回。
- `tools/release.py validate` 和 `tools/release.py package` 用于发行检查及冻结包校验。

## 美术与本地化

自制四向精灵 `suqing_freshness_fridge_01_0..3` 对应南、东、北、西，PZPK 纹理包和 tiledef ID 为 7825。Viewpoint 模型包含 562 个三角面、UV、PNG 材质和四向绑定，按 Z-up OBJ 规则导出。标准等距视角使用独立 2D 精灵。

封面为用户选定的 B「夜间工坊」，母版及提示词保留在 `art/cover-candidates_20261105`。独立图标母版、提示词及 64/128/256 尺寸导出位于 `art/icon-source.png`、`art/icon-generation.json` 和 `art/icon-exports`。原始封面和角色参考仍保留。`tools/assets_build.py` 生成建筑资源，`tools/export_selected_cover.py` 导出封面和独立图标。
